# Задача о рюкзаке. Генетический алгоритм.

### Вариант 2:
Решить задачу о рюкзаке с применением генетического алгоритма, с учетом следующих требований:
   - Придумать условия задачи с количеством предметов не менее 8.
   - Численность популяции не менее 6 особей, в скрещивании участвует 1/3 популяции. 
   - Для скрещивания выбираются сильнейшие особи, скрещивание – двухточечное.
   - До выполнения алгоритма сформулировать стратегию применения оператора мутации и правила формирования нового поколения на основе новых особей и особей из предыдущего поколения.
   - Сформировать не менее 3 поколений, не считая первоначального.
  

Основные шаги генетического алгоритма:
- Инициализация: Создается начальная популяция случайных решений (особей).
- Оценка: Каждое решение оценивается с помощью функции приспособленности (фитнес функция), которая измеряет качество решения.
- Отбор: На основе оценки приспособленности выбираются решения, которые будут использоваться для создания нового поколения. Чем выше приспособленность, тем больше шансов у решения быть выбранным.
- Кроссовер (скрещивание): Выбранные решения комбинируются для создания новых решений. Это может происходить различными способами, но обычно включает в себя обмен частями двух решений.
- Мутация: С небольшой вероятностью некоторые части новых решений случайным образом изменяются для добавления вариативности.
- Новое поколение: На основе новых особей и особей предыдущей популяции формируется новое поколение, и процесс повторяется с шага оценки.

Этот алгоритм продолжает работу до тех пор, пока не будет достигнут критерий остановки, например, максимальное количество поколений или достижение достаточно хорошего решения.

## Стратегия применения оператора мутации  

Генетический оператор мутации будем применять в случае, когда суммарный вес предметов, входящих в особь, превышает вместимость рюкзака.

## Правило формирования нового поколения на основе новых особей и особей из предыдущего поколения

Перед формированием каждого нового поколения будет построена рейтинговая таблица, в которой особи будут ранжированы по убыванию значения фитнес-функции. На основе таблицы будет составлено неравенство, на основе которого в формировании следующего поколения будут участвовать 6 самых сильных особей. 

## Разрешение ситуации наличия клона

При обнаружении среди новых особей клона другой особи из текущего поколения, данный клон будет удален и не будет участвовать в формировании следующих поколений.

## Формирование 1-го поколения

Обозначим особи поколения как X<sub>1</sub>, X<sub>2</sub>, X<sub>3</sub> и т.д.  

Далее рандомно составим хромосомы (символьные строки) каждой особи. Номерами от 1 до 8 обозначены гены хромосомы.

### 1 поколение
|  | **№1** | **№2** | **№3** | **№4** | **№5** |**№6** | **№7** | **№8** | 
| -------------| :-----: | :-----: | :-----: | :-----: | :-----: | :-----: | :-----: | :-----: |
| **X<sub>1</sub>**        |  0  |   1  |   0   |   0 |   1   |  0   |   1   |   0   | 
| **X<sub>2</sub>**       |  1   |   1   |   0  |  1  |  0  |  0   |  0  |  1  |
| **X<sub>3</sub>**       |  0   |   0   |   1  |  0  |  0  |  1   |  1  |  1  |
| **X<sub>4</sub>**       |  0   |   0   |   0  |  1  |  1  |  1   |  0  |  0  |
| **X<sub>5</sub>**       |  0   |   1   |   0  |  1  |  0  |  1   |  0  |  1  |
| **X<sub>6</sub>**       |  1   |   0   |   1  |  0  |  0  |  0   |  1  |  0  |

У каждой особи посчитаем фитнес-функцию (сумму стоимостей предметов, которые входят в хромосому. 1 в символьной строке значит, что данный предмет входит в хромосому, 0 - не входит). Перед тем как считать фитнес-функцию, необходимо проверить, что суммарный вес предметов у особи не больше вместимости рюкзака.

Для особи X<sub>1</sub>:  
вес = 5 + 1 + 2 = 8,  8 <= 20 => не нарушает условия вместимости  
f(X<sub>1</sub>) = 8 + 1 + 2 = 11

Для особи X<sub>2</sub>:  
вес = 8 + 5 + 3 + 4 = 20,  20 <= 20 => не нарушает условия вместимости  
f(X<sub>2</sub>) = 13 + 8 + 6 + 3 = 30

Для особи X<sub>3</sub>:  
вес = 10 + 3 + 2 + 4 = 19,  19 <= 20 => не нарушает условия вместимости  
f(X<sub>3</sub>) = 20 + 8 + 2 + 3 = 33

Для особи X<sub>4</sub>:  
вес = 3 + 1 + 3 = 7,  7 <= 20 => не нарушает условия вместимости  
f(X<sub>4</sub>) = 6 + 1 + 8 = 15

Для особи X<sub>5</sub>:  
вес = 5 + 3 + 3 + 4 = 15,  15 <= 20 => не нарушает условия вместимости  
f(X<sub>5</sub>) = 8 + 6 + 8 + 3 = 25 

Для особи X<sub>6</sub>:  
вес = 8 + 10 + 2 = 20,  20 <= 20 => не нарушает условия вместимости   
f(X<sub>6</sub>) = 13 + 20 + 2 = 35  

Ранжируем особи по их фитнес-функции:   
f(X<sub>6</sub>) > f(X<sub>3</sub>) > f(X<sub>2</sub>) > f(X<sub>5</sub>) > f(X<sub>4</sub>) > f(X<sub>1</sub>)

Так как необходимо сформировать минимум 3 поколения, алгоритм не закончен. Далее используем генетический оператор скрещивания. В нашем варианте выбор родителей будет формироваться через принцип элитизма, то есть к скрещиванию допускаются две (1/3 популяции) сильнейших особи. В данном поколении это особи **X<sub>6</sub>**  и **X<sub>3</sub>**.

Применим двухточечное скрещивание. Выберем рандомно две точки между генами: первая - между 2 и 3 геном, вторая - между 6 и 7. Таким образом, с помощью этих точек символьная строка будущих потомков разделена на 3 части: у первого потомка 1 и 3 часть будут взяты у родителя X<sub>6</sub>, а 2 часть у родителя X<sub>3</sub>; у второго потомка зеркально - 1 и 3 часть будут взяты у родителя X<sub>3</sub>, а 2 часть у родителя X<sub>6</sub>.  

Так будут выглядеть новые особи X<sub>7</sub> и X<sub>8</sub>.

|  | **№1** | **№2** | **№3** | **№4** | **№5** |**№6** | **№7** | **№8** | 
| -------------| :-----: | :-----: | :-----: | :-----: | :-----: | :-----: | :-----: | :-----: |
| **X<sub>7</sub>**       |  1   |   0   |   1  |  0 |  0  |  1   |  1  |  0  |
| **X<sub>8</sub>**       |  0  |   0   |   1  |  0  |  0  |  0   |  1 |  1  |

Для каждой новой особи посчитаем фитнес-функцию, предварительно проверив, что условие вместимости в рюкзак не нарушается.

Для особи X<sub>7</sub>:  
вес = 8 + 10 + 3 + 2 = 23,  23 > 20 => нарушает условия вместимости, нужно применить генетический оператор мутацию  

Применение мутации подразумевает инвертацию одного из генов особи. Так как нам нужно добиться того, чтобы особь не нарушала условия вместимости в рюкзак, необходимо одну из единиц в символьной строке поменять на 0. Так как у особи X<sub>7</sub> самый тяжелый предмет это №3, то заменим в ячейке этого гена 1 на 0. Так будут выглядеть обновленные гены:

|  | **№1** | **№2** | **№3** | **№4** | **№5** |**№6** | **№7** | **№8** | 
| -------------| :-----: | :-----: | :-----: | :-----: | :-----: | :-----: | :-----: | :-----: |
| **X<sub>7</sub>**       |  1   |   0   |   0  |  0 |  0  |  1   |  1  |  0  |


вес = 8 + 3 + 2 = 13,  13 <= 20 => не нарушает условия вместимости   
f(X<sub>7</sub>) = 13 + 8 + 2 = 23

Для особи X<sub>8</sub>:  
вес = 10 + 2 + 4 = 16,  16 <= 20 => не нарушает условия вместимости   
f(X<sub>8</sub>) = 20 + 2 + 3 = 25
