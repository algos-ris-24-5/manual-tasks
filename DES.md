## Шаг 2. Поиск максимального потока

Теперь ищем максимальный поток. Чтобы выполнить требования задачи, мы специально используем пути, которые включают дорогие дуги — это позволит позже уменьшать стоимость через отрицательные циклы.

Мы пропускаем поток по двум путям:

- **s → c → a → t** — 10 единиц  
- **s → d → a → t** — 2 единицы  

Так получаем максимальный поток:

**|f| = 12**

## Шаг 4. Остаточная сеть и первый отрицательный цикл

Строим остаточную сеть.  

- если по дуге можно увеличить поток — прямая дуга с весом **+c(e)**  
- если по дуге уже идёт поток — обратная дуга с весом **−c(e)**  

Это позволяет увидеть, где можно «откатить» поток и уменьшить стоимость.

**Граф 3 — остаточная сеть с весами**  
<img width="877" height="797" alt="3" src="https://github.com/user-attachments/assets/4b4dac20-7582-428a-8a88-f38af3f2ff15" />


В этой сети появляется отрицательный цикл:

**d → b → a → d**  
Стоимость цикла: **1 + 1 − 3 = −1**

**Граф 4 — цикл отрицательной стоимости**

Мы можем перебросить по этому циклу максимум **θ = 2**.  
После корректировки стоимость уменьшается:

**94 − 2 = 92**


## Шаг 5. Повторные корректировки потока

После первой корректировки в остаточной сети остаются возможности для удешевления.  
Мы продолжаем искать отрицательные циклы и перебрасывать поток.

### Вторая корректировка

Мы уменьшаем поток по более дорогому пути и увеличиваем по более дешёвому.  
Это снова даёт цикл со стоимостью **−1**, и мы можем перебросить **θ = 4**.

Новая стоимость:

**92 − 4 = 88**

### Третья корректировка

Находим ещё один цикл:

**s → d → b → a → c → s**

Здесь можно перебросить **θ = 4**, и стоимость уменьшается ещё на 8:

**88 − 8 = 80**
