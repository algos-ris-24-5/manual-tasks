# Задание №7+
# Задача об оптимальном распределении инвестиций. Метод «Stars and Bars».

В файле `Задание 7+\Задача о распределдении инвестиций.md` представлены теоретические материалы по теме "Динамическое программирование и Задача о распределдении инвестиций". Необходимо изучить метод «Stars and Bars» (звёздочки и перегородки), понять как он связан с задачей о распределении инвестиций и дополнить теоретические материалы, написав раздел Метод «Stars and Bars» (звёздочки и перегородки) в файле `Задание 7+\Задача о распределдении инвестиций.md`, в том числе пример использования описываемого метода для условий задачи о распределдении инвестиций из представленного примера.

## Для выполнения задания необходимо:

1. Обновить ветку main в локальном репозитории (git pull).
2. От ветки main создать ветвь с названием `<название_команды>-task-7-plus`, заменив `<название_команды>` на название команды, решившей задание.
3. Зафиксировать изменения на ветке (git commit).
4. Отравить ветку с изменениями в репозиторий на Github (git push).
5. Создать на Github запрос на слияние (pull request), указав в качестве base ветки `main`, в качестве compare ветки `<название_команды>-task-7-plus`.
